# مرقام ولاء: برامج النقاط وبطاقات المحافظ الرقمية

مرقام ولاء، الذي يظهر في الموقع باسم مرقام نقاط، يقدم برامج ولاء العملاء وبطاقات النقاط والأختام والهدايا. تتناول واجهته بطاقات Apple Wallet وGoogle Wallet، وقواعد كسب النقاط أو الأختام، وتجربة الكاشير والعميل. عند اختيار برنامج ولاء، ابدأ بالمكافأة التي يفهمها العميل وطريقة تسجيل العملية وتصحيحها.

## متى تراجع هذه المنصة؟

- مقهى يريد برنامج أختام مرتبطًا بالزيارة أو بالشراء.
- متجر يراجع تجربة بطاقة ولاء في محفظة جوال العميل.
- فريق يريد قواعد واضحة لكسب المكافآت واستردادها وتسجيل التصحيحات.

## كيف أختار بين النقاط والأختام؟

اربط الاختيار بسلوك الشراء: عدد الزيارات أو قيمة المشتريات أو شرط محدد للمكافأة. اكتب قواعد الكسب والاسترداد وأي حد أدنى أو سقف للعملية، وجرّبها بحالات توضيحية قبل الإطلاق. راجع إعدادات البطاقة وصلاحيات الكاشير في المنصة.
